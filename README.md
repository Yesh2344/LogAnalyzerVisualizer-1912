## Overview

`Log Analyzer & Visualizer` is a production‑ready CLI tool that parses structured log files, extracts useful metrics, and generates an interactive HTML dashboard with charts. It demonstrates modern JavaScript practices, robust error handling, and clean architecture.

## Features

- ✅ Configurable via **.env** (log path, output folder, etc.)
- 📊 Generates an HTML report with **Chart.js** (no extra runtime dependencies)
- 🪵 Structured logging with **Winston**
- 🧪 Unit‑tested core logic (Jest)
- 📦 Fully typed with JSDoc for IDE autocomplete
- 🚀 Zero‑runtime external services – pure Node.js
